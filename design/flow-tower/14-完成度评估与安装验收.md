## 4 试用方式（已装好）

### 4.1 直接使用

- 在本机 DSH 会话里，模型可调用 6 个 `dict_*` 工具；
- 打开 **http://127.0.0.1:10935/flow-tower/** 查看词典/树/时间线/任务/关系图；
- 词典按项目存放：`<项目根>/.flow-tower/flow_tower.db`（共享给同项目所有会话，自动 `.gitignore`）。

### 4.2 推荐配置（默认已合理）

```yaml
# 插件补丁行默认值（plugin/flow-tower/cordis.patch.yml）
maxEntries: 4000
storageMode: project
relationsMode: shadow     # 建图+只读
llmCompiler: 'off'        # 需要时改 shadow 试
proposalMode: 'off'
```

### 4.3 回滚 / 卸载

| 动作 | 做法 |
| --- | --- |
| 临时停用 | `plugin_manager remove_bundle target=@local/flow-tower` |
| 彻底清理数据 | 删除各项目下 `.flow-tower/`（会话原文不受影响） |
| 关闭单一能力 | `relationsMode: off` 关关系图；`llmCompiler: off` 关 LLM；`digestMode: off` 关注入 |
| 只回退版本 | `install_bundle` 指定旧目录/旧 tarball |

### 4.4 启用 LLM shadow（待做的一次真实验证）

1. 把 `llmCompiler` 改为 `shadow`，重载插件；
2. 让一个真实会话发生一次压缩；
3. 查 `metrics` 中 `kind='llm-proposals'` 的 accepted/rejected/ms 与词条增量；
4. 满意后改 `on`。
