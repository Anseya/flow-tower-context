# 19 · 从零评估：Context Flow Tower v0.41（2026-11-15）

> 立场：这次不引用此前"综合 8.1/10"的宣传口径，而是从**代码、测试、线上数据、真实交互**重新打分。
> 评分是定性 1–10；对 DSH 场景加权；竞品未在本机复跑，只作能力画像，不当 benchmark。

## 0. 一句话结论

**DSH 项目上下文场景：7.8/10（工程上很强，智能上偏弱）。**
**作为通用 AI 记忆平台：约 5.8/10（不是这档产品）。**
**作为研究型语义记忆：约 5.5/10。**

## 1. 它到底解决什么问题

目标用户是"在 DSH 里长期做工程项目的人"：
- 压缩发生后，之前的设计决策、任务、文件关系不丢；
- 能按项目/模块/任务/时间/叙事找回来；
- 每条结论能回放原文，不是模型编的摘要；
- 数据在项目本地，不依赖外部服务。

**它不解决**：通用聊天记忆、跨应用个人助理、知识库 RAG、多 agent 调度。

## 3. 从零确认"还不够好"的部分（这次不护短）

| 问题 | 事实 |
| --- | --- |
| 语义召回弱 | 默认仍是词法/稀疏；真实 embedding 未配置；aliases 只有 LLM shadow/on 才生成；没有 query rewrite/rerank |
| 任务抽取噪声 | 任务来自压缩摘要的 TODO/下一步句，仍有碎片；32 个任务里不少是长句/代码片段 |
| 任务上下文是"证据邻近" | taskContext 基于 citation seq ±8，不是人工确认的语义归属 |
| 依赖宿主压缩 | 不压缩就不编纂；没有"主动总结"能力 |
| 其他宿主不支持 | 深度绑定 DSH 的 event/session/web/model 接口，无 adapter |
| 前端曾被 JS 语法错误整段打挂 | 现已修复；但说明缺少浏览器 E2E 测试 |
| Client 缓存 | 宿主会缓存 client bundle；现在面板内有"刷新界面/刷新数据"按钮，但仍是被动方案 |
| 内容翻译 | 按用户要求只做 UI 双语，词典内容保留原文；不算缺陷，但英文用户体验受限 |
| MCP 未自动接线 | 有独立 stdio server，需手动配置 |
| 安全 | 本地 HTTP API 无鉴权/CSRF，仅 loopback；单写者 |
| 评测样本自指 | 1994 词条来自"开发本插件"的对话，不是外部业务基准 |

## 6. 最大的工程风险/技术债

1. **语义是天花板**：没有真实 embedding/LLM rerank，分数上不去；
2. **任务质量**：从压缩摘要抽任务，先天信息不足；应改为观察原始 user/assistant 消息；
3. **宿主耦合**：DSH-specific 接口应抽象 adapter（虽然当前先做 DSH，但别写死）；
4. **前端不可测**：无浏览器 E2E，曾出现整页 JS 挂掉；
5. **Client 缓存**：刷新按钮是补丁，不是根解；
6. **配置分层反直觉**：settings 文件会覆盖 patch 的 llmCompiler（曾导致 shadow 打不开）；
7. **单写者/无鉴权**：本地工具可接受，但别对外暴露；
8. **评测偏差**：当前数据都是"开发本插件"的自指语料，不能当业务泛化。

## 7. 建议的下一步（按投入回报）

### P0（1–2 周）
1. 真实 embedding provider（本地/云）+ 30–50 条 recall@5 基准；
2. 任务识别改从原始消息抽取，提高任务对象质量；
3. 浏览器 E2E（至少页面 JS 不挂、语言/刷新/设置生效）；
4. 面板"刷新"验证 + settings 覆盖 patch 的提示/修复；
5. 前端 label 全量清点（当前重点 UI 已覆盖）。

### P1（2–4 周）
6. LLM query rewrite/rerank 或 aliases 真正生成（shadow 审核）；
7. MCP 自动接入 DSH；
8. 导出/导入 UI 完整闭环；
9. HostAdapter 抽象（先 DSH，后扩展）。

### P2
10. 多项目规模/LRU 实机验证；
11. API token/CSRF、单写者文档化；
12. 内容视图标签可选本地化（不翻译数据）。

## 8. 刷新功能说明

- 面板标题栏 **↻**：`window.location.reload()`，重载整个 DSH 页面，解决 Client bundle 缓存；
- iframe 页头 **↻**：重跑 `renderCatalog + loadTab`，只刷新数据，不重载页面；
- 两者都不改内容语言（内容保留原文，UI 才双语）。
